# Fontes e organização

- Base de conteúdo recebida: `Duas_cerejas_site_raiz.zip`.
- `Duas_Cerejas_V3_Otimizada.zip` foi usada apenas como referência de linguagem de movimento e encerramento, não como base de código.
- Os arquivos usados pelo navegador foram renomeados para nomes ASCII, sem espaços e em minúsculas.
- As fotografias originais não foram alteradas; foram gerados derivados WebP.
- Para manter o pacote executável leve, os masters originais permanecem no ZIP de origem e não foram duplicados nesta candidata.
